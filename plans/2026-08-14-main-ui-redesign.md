# 主畫面UI重新規劃：PTF表格化 + 排版整理

最後更新：2026-08-14。這份計畫回應兩輪前的回饋：「PTF需求資訊要用table方式呈現，原文沒列出的留空不要顯示」＋「主畫面排版有夠亂，要認真規劃UI」。**上一輪這份計畫被我漏掉沒有產出，這次補上，尚未實作。**

## 問題根源：一直用補丁疊補丁，沒有從頭想過資訊架構

回顧這幾輪的異動軌跡：一開始只有一個 `.tag`（OS版本），後來加 `.tag-row`，再改成 `.spec-grid`/`.spec-item` 兩欄對等呈現，`ptfInfo` 全程都是一整段自由文字、越寫越長（尤其套用官方PTF層級資料後，例如 `active_job_info` 的PTF資訊有7、8個PTF編號串成一句話）。每次都是針對單一意見做局部調整，沒有回頭檢視「一張卡片到底該放多少資訊」，結果就是卡片越疊越高、越來越難掃視。這輪要從資料結構跟版面兩層一起重新想。

## 一、資料結構：`ptfInfo` 從自由文字改成結構化表格資料

### 現況
```json
"ptfInfo": "各版本另有 Enhanced 強化功能PTF層級：7.5=SF99950 Level 3/8/9；7.4=SF99704 Level 7/10/13/15/20/23/29；7.3=SF99703 Level 11/18/22/24/26/28（層級越高新增/強化欄位越多）。7.6官方頁面僅標示「Base Enhanced」未列出具體PTF編號，原文如此。"
```
一整段文字，版本號、PTF編號、「原文沒寫清楚」的meta說明全部黏在一起，沒辦法只挑重點掃視，而且7.6「查不到」這件事被迫用一句話講出來，你要的是**查不到就留空、不要顯示任何替代文字**。

### 新結構（草案，供你確認）
```json
"ptfTable": [
  { "version": "7.6", "base": true, "enhanced": "" },
  { "version": "7.5", "base": true, "enhanced": "SF99950 Level 3/8/9" },
  { "version": "7.4", "base": true, "enhanced": "SF99704 Level 7/10/13/15/20/23/29" },
  { "version": "7.3", "base": true, "enhanced": "SF99703 Level 11/18/22/24/26/28" }
]
```
- 每個版本一列，`base` 是否為Base功能、`enhanced` 是額外強化PTF編號（沒有資料就是空字串，畫面上該格直接留空，不寫任何說明文字）。
- `ASP_INFO` 這種「7.3非Base」的例外：`{ "version": "7.3", "base": false, "enhanced": "SF99703 Level 7以上（非Base門檻）Enhanced至Level 15" }`，`base:false` 讓畫面可以用不同樣式標示（例如顏色區分「原生內建」vs「需額外PTF」）。
- 舊的3筆未驗證資料（`OBJECT_LOCK_INFO`／`SYSTABLESTAT`／`IFS_OBJECT_STATISTICS`）目前是「群組PTF家族名稱、無逐版驗證」這種概略描述，沒有官方對照表可拆成逐版表格，這3筆會維持用一段簡短說明文字（不勉強塞進表格結構），並在畫面上用跟其他7筆不同但一致的樣式呈現「未逐版驗證」，不是塞進表格空格裡湊數。
- `minOsVersion`／`versionNotes` 保留現有欄位不變，畫面呈現方式一起在下面第二節調整。
- `docs/data-schema.md` 需要同步補上這個新欄位的說明跟範例。

## 二、版面：卡片精簡化 + 細節收合

### 設計原則（沿用先前查過的progressive disclosure）
列表卡片只留「一眼掃過去就能判斷這個service是不是我要的」所需資訊，細節資料按需展開，不要預設全部攤開。

### 新的卡片結構
**常駐顯示（不需點擊就看得到）**：
- Service名稱 + 分類
- 一句話用途說明
- 已核實／草稿 徽章
- 「產生SQL」按鈕

**收合在「顯示規格詳情 ▾」按鈕後面（沿用表單那邊已經做好的展開/收合UI模式，不用重新設計一套新元件）**：
- 最低OS版本
- PTF對照表（表格）
- 版本例外提示（如果有）

這樣預設狀態下，一頁可以掃視完整10張卡片的名稱跟用途，不用像現在這樣捲很久才看完幾張卡；有需要查PTF細節時再點開。

### 表格的CSS呈現
簡單的HTML `<table>`，欄位：版本／Base／Enhanced PTF。沒資料的儲存格留空即可，不需要特殊樣式；`base:false` 的列可以用淺色底或文字顏色標出「非Base」。
